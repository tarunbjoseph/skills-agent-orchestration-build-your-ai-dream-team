# Agent Team Summary

For Project Pulse, our team uses these roles:

- Orchestrator: coordinates work across specialists.
- Planner: creates implementation plans.
- Coder: implements and tests code changes.
- Designer: improves UX and visual polish.

Model assignments:

- Orchestrator and Planner use Opus 4.7.
- Coder uses GPT-5.5.
- Designer uses Gemini 3.1 Pro.

All agent definitions are kept under `.github/agents`.
